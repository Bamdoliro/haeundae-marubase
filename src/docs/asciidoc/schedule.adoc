== 입학 일정 Schedule

입학 전형 일정(원서 접수, 합격 발표, 면접, 입학 등록, 출결 기준일)을 관리합니다.
활성 일정은 하나이며, 등록된 일정이 없으면 조회 API는 404를 반환합니다.

시간 순서는 다음을 만족해야 합니다. 어기면 400(`INVALID_SCHEDULE_PERIOD`)을 반환합니다.

* 원서 접수 시작 <= 방문 원서 접수 < 원서 접수 마감 < 1차 합격 발표 < 2차 면접 시작 < 2차 면접 종료 < 최종 합격 발표 < 입학 등록 시작 < 입학 등록 마감
* 출결 기준일 <= 원서 접수 마감일

=== 현재 입학 일정 수정
어드민은 현재 활성 일정을 수정할 수 있습니다. 요청 본문은 등록과 같고, 조회한 일정의 `version`을 함께 보내야 합니다.
다른 관리자가 먼저 수정했다면 409(`SCHEDULE_VERSION_CONFLICT`)를 반환하므로, 다시 조회한 뒤 수정해야 합니다.
