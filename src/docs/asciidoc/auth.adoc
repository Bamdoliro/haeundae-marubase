== 인증 Auth

=== 로그인
전화번호와 비밀번호를 입력해 로그인을 할 수 있습니다.
토큰은 응답 바디가 아니라 HttpOnly 쿠키(accessToken, refreshToken)로만 내려가며, 정상 응답은 바디 없는 204 No Content입니다.

=== 액세스 토큰 재발급

새 액세스 토큰은 accessToken 쿠키로만 내려가며, 정상 응답은 바디 없는 204 No Content입니다.

=== 세션 정리
재발급이나 로그아웃에 실패해 세션이 이미 깨졌을 때, 브라우저에 남은 인증 쿠키(accessToken, refreshToken)를 만료시킵니다.
인증 없이 호출할 수 있고, 쿠키가 없어도 같은 응답을 내려줍니다. 서버에 저장된 리프레시 토큰은 지우지 않습니다(로그아웃과 다른 점).
정상 응답은 바디 없는 204 No Content입니다.
